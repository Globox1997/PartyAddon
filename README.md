# PartyAddon
PartyAddon is a mod addon for the [LevelZ](https://www.curseforge.com/minecraft/mc-mods/levelz) mod and adds player parties.

### Installation
PartyAddon is a mod built for both the [Fabric Loader](https://fabricmc.net/) and [NeoForge](https://neoforged.net/).

- **Fabric:** requires [Fabric API](https://www.curseforge.com/minecraft/mc-mods/fabric-api), [LevelZ](https://www.curseforge.com/minecraft/mc-mods/levelz), [LibZ](https://www.curseforge.com/minecraft/mc-mods/libz) and [Cloth Config API](https://www.curseforge.com/minecraft/mc-mods/cloth-config) to be installed separately.
- **NeoForge:** requires [Cloth Config API](https://www.curseforge.com/minecraft/mc-mods/cloth-config), [LevelZ](https://www.curseforge.com/minecraft/mc-mods/levelz) and [LibZ](https://www.curseforge.com/minecraft/mc-mods/libz) to be installed separately.

### Commands
`/party invite <player>`: Invite a player to your group
`/party accept`: Accept open invitation
`/party decline`: Decline open invitation  
`/party leave`: Leave group
`/party kick <player>`: Kick a group member (leader only)  
`/party promote <player>`: Make a group member the new leader (leader only)  
`/party list`: List your group members
